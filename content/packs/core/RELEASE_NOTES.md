# Agents Pack Core 0.31.1

- Strengthen design exploration with binding creative packets and three varied
  originality methods: art direction, reference collision, and anti-convergence.
- Require every concept to use a content-native composition rule, name its
  probable generic fallback, and preserve explicit rejection checks through
  implementation.
- Isolate sibling concept implementations by default so one design does not
  anchor the others back toward the same visual solution.
- Add typography safeguards throughout implementation, criticism, polish, and
  frontend review for accidental text collisions, near-tangencies, clipped
  glyphs, and excessive use of bold weights.
- Expand rendering tests to verify the creative-packet reference is included in
  Claude, Codex, and Cursor installations.
